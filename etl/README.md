# База олимпиадных задач

Парсер `parser_sdamgia_v2.py` собирает задачи с разделов СДАМ ГИА по [математике](https://math-olymp.sdamgia.ru) и [физике](https://phys-olymp.sdamgia.ru) в SQLite. Он работает через `requests` и Beautiful Soup, без браузера.

## Как собирали

Первый проход по тематическому каталогу дал неполный набор задач. Поэтому базу заново наполнили прямым обходом страниц `/problem?id=N`: для математики — ID 1–12691, для физики — 1–8035. Это максимальные ID, обнаруженные на момент сбора 24 сентября 2026 года; при появлении новых задач границы в `SUBJECTS` нужно увеличить. Запросы выполняются в 16 потоков с повторами при ошибках. Из страницы берутся условие, метаданные, решение и ответ. Вместо изображений сохраняется их `alt`, выделенный `$...$`; если `alt` пуст, изображение в тексте не представлено.

В результате: 11 929 задач по математике и 7 724 по физике (19 653 всего). Ещё 762 и 311 ID соответственно сайт сообщил как недоступные или несуществующие. Эти числа относятся к указанному снимку базы, а не к постоянно обновляемому сайту. Часть полей может быть пустой, если сайт не публикует их или текст задачи дан только картинкой без `alt`.

## База и повторный запуск

Файл `olimpiads_data_v2/olimpiads.sqlite3` содержит таблицы `problems` (одна задача на пару `subject, problem_id`) и `unavailable_ids` (проверенные недоступные ID). Повторный запуск пропускает обе группы; ошибки загрузки и разбора пишет в `olimpiads_data_v2/olimpiads.errors.log` и оставляет эти ID для следующего запуска.

```bash
python3 -m pip install -r requirements.txt
python3 parser_sdamgia_v2.py
```

Путь к базе можно изменить через `--db путь/к/базе.sqlite3`. База, резервные копии и логи лежат в `olimpiads_data_v2/` и не добавляются в Git.

## Поиск по задачам

Поиск использует Qwen3-Embedding-4B через OpenRouter и FTS5 **в исходной SQLite-базе** `olimpiads_data_v2/olimpiads.sqlite3`. На проверенном снимке в ней 19 653 задач и 39 235 векторов; ключ и база исключены из Git. Подробности подготовки текстов, схемы, обновления, ранжирования и проверок — в [SEARCH.md](SEARCH.md).

```bash
python3 -m pip install -r requirements.txt
./run_search_index.sh
.venv/bin/python task_search.py --api-key-file olimpiads_data_v2/openrouter.key search \
  'закон сохранения импульса' --mode topic --subject physics -k 5
```

Для замера размера пакета используйте `benchmark_batch_sizes.py`, для сравнения методов по размеченным запросам — `evaluate_search.py`.

## Оценка сложности задач

Для задач подготовлена шкала сложности 1–10 и разметчик на Jev через OpenRouter. Описание шкалы, промпта, пилотной выборки и запуска — в [DIFFICULTY.md](DIFFICULTY.md). Полная разметка выполняется отдельно и записывает результат в `problems.difficulty`.
