# Сложность задач

`label_difficulty.py` передаёт Jev предмет, класс, условие и решение. Jev
оценивает, насколько трудно подготовленному ученику этого класса найти решение.
Сырые оценки переводятся в целые уровни 1–10; вероятности модель не сохраняет.

Шкала начинается с самой доступной задачи своего олимпиадного уровня. Верхние
баллы означают несколько неочевидных идей и трудное доказательство. Полные
критерии заданы в `label_difficulty.py`.

Сначала проверили шкалу на 300 случайных задачах — по 150 на предмет; 20 задач
оценили дважды. Распределение было похоже на колокол с пиком на 4, повторные
целые оценки совпали. Затем размечены все задачи с непустым условием: 11 924
по математике и 7 716 по физике. У 13 задач нет условия, поэтому они пропущены.
В 25 пилотных условиях упоминался рисунок, изображения модель не видела.

```bash
python3 -m labeling.label_difficulty --batch-size 32 --workers 8
```

Размер группы задаёт `--batch-size`, число одновременных запросов —
`--workers`. Каждая оценка сразу сохраняется в SQLite. Повторный запуск
продолжит с неразмеченных строк. Ключ берётся из `OPENROUTER_API_KEY` или
`olimpiads_data_v2/openrouter.key`; прокси — из `HTTPS_PROXY` или
`http://127.0.0.1:12334`.

`pilot_difficulty.py` создаёт воспроизводимую случайную выборку и сохраняет
пробные ответы отдельно от основной базы. Например:

```bash
python3 -m labeling.pilot_difficulty --per-subject 150 --repeats 20
```
