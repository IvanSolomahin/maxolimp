# Решение задач и статистика

## Функциональные требования (ФТ)

### Аутентификация

- **ФТ-01.** В мини-приложении MAX система должна автоматически аутентифицировать пользователя на основании его аккаунта MAX.
- **ФТ-02.** При открытии приложения вне MAX система должна предлагать пользователю зарегистрироваться с помощью email и пароля.
- **ФТ-03.** Система должна связывать список решённых задач с учётной записью пользователя.

### Решение задач

- **ФТ-04.** Ввод ответа, раскрытие эталонных материалов и отметка о решении должны быть доступны на экране просмотра задачи.
- **ФТ-05.** Пользователь должен иметь возможность ввести ответ на задачу.
- **ФТ-06.** До отправки введённого ответа система должна скрывать эталонные ответ и решение задачи.
- **ФТ-07.** После отправки ответа система должна показать доступные эталонный ответ и решение.
- **ФТ-08.** Система не должна автоматически оценивать правильность введённого ответа в первой версии. Пользователь сам определяет, верно ли решил задачу.
- **ФТ-09.** После отправки ответа пользователь должен иметь возможность отметить задачу решённой.
- **ФТ-10.** При отметке задачи решённой система должна добавить её в список решённых пользователя.
- **ФТ-11.** Если задача уже находится в списке решённых, повторная отметка не должна изменять список.
- **ФТ-12.** Система не должна сохранять неверные ответы и неудачные попытки.
- **ФТ-13.** Если у задачи отсутствует эталонный ответ или решение, система должна показывать только имеющиеся материалы.

### Статистика

- **ФТ-14.** Система должна предоставлять отдельный экран персональной статистики, доступный из меню навигации.
- **ФТ-15.** Система должна показывать на экране статистики задачи из списка решённых пользователя.
- **ФТ-16.** Статистика должна включать недельный, месячный и годовой периоды.
- **ФТ-17.** Система должна позволять просматривать статистику с разбивкой по олимпиадам.
- **ФТ-18.** Система должна позволять просматривать статистику с разбивкой по тегам задач.
- **ФТ-19.** Повторное решение уже отмеченной задачи не должно повторно увеличивать статистику.

## Нефункциональные требования (НФТ)

- **НФТ-01.** Данные списка решённых задач должны сохраняться между сеансами пользователя и быть доступны после повторной аутентификации.
- **НФТ-02.** Доступ к списку решённых задач и статистике должен предоставляться только аутентифицированному владельцу этих данных.
- **НФТ-03.** Успешная аутентификация в MAX должна подтверждаться сервером по данным платформы; клиентские данные сами по себе не должны считаться подтверждением личности.
- **НФТ-04.** Статистика должна рассчитываться по сохранённым отметкам решённых задач; неудачные попытки в расчёты не входят.

## Не входит в первую версию

- Автоматическая проверка ответа для числовых, текстовых и математических форматов.
- Сохранение истории неверных ответов и попыток.
- Генерация отсутствующих ответов и решений через GigaChat; это требование описывается отдельно.

## Реализация первой версии

Учётные записи, сессии и отметки решений хранятся в `task-db` в таблицах
`users`, `user_sessions` и `solved_tasks`. Для существующей базы перед запуском
новой версии сервиса задач применяется `task_find_service/sql/migrate_v7.sql`.
Новых пользователей MAX переносить не требуется.

Публичные маршруты: `POST /api/max/validate`, `POST /api/auth/register`,
`POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`,
`GET /api/progress/tasks/{task_id}`,
`POST /api/progress/tasks/{task_id}/solved`, `GET /api/progress/solved` и
`GET /api/progress/statistics`. Маршруты прогресса используют сессию в cookie;
параметр `user_id` от клиента не принимается. Архив поддерживает `page`, `size`,
`period`, `olympiad_id` и `tag`. Статистика поддерживает `period`,
`olympiad_id` и `tag`; тегом служит `tasks.classifier`.

Периоды: 7 дней, 30 дней и 12 календарных месяцев включая текущий.
Границы дат определяются по `Europe/Moscow`. Эталон скрывается до отправки
ответа только в интерфейсе; публичные API задачи и решения по-прежнему его
отдают. Введённый ответ остаётся в браузере до перехода к следующей задаче и
не передаётся на сервер.
