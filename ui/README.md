# Интерфейс Maxolimp

Основное приложение находится в `src/` и построено на Vue 3, Vue Router, Vite и TypeScript. Каталог `public/` содержит прежнюю реализацию и сохранён для справки; Vite настроен с `publicDir: false`, поэтому эти файлы не входят в сборку.

## Локальная разработка

```bash
cd ui
npm ci
npm run dev
```

Vite проксирует `/api/tasks/*` на `localhost:8000`, `/api/olympiads/*` на `localhost:8001`, а `/api/max/*` на `localhost:8000`. Для работы данных запустите оба API. Проверка типов и production-сборка: `npm run build`.

## Развёртывание и адреса

Образ `ui/Dockerfile` собирает приложение и копирует `dist/` в Nginx. `docker-compose.yml` больше не монтирует исходники в контейнер, а `scripts/deploy.sh` пересобирает frontend при изменениях приложения. Основные адреса: `/`, `/olympiads`, `/olympiads/:id`, `/tasks`, `/tasks/:id`, `/practice`, `/statistics`, `/communities`. Nginx перенаправляет прежние `*.html` адреса.

Отметки о решении хранятся локально в браузере по ID задачи и дате. Старые отметки по названию остаются в архиве без дат. Персональное хранение на сервере пока не реализовано.

## Архив прежнего интерфейса

Ниже описаны файлы прежней реализации. Они сохранены в `public/` для справки и не используются новым приложением.

### Файлы интерфейса (`ui`)

Каталог содержит статический веб-интерфейс Maxolimp и конфигурацию Nginx, который его раздаёт. Страницы расположены в `public/`; общие сценарии и стили подключаются отдельными файлами, а стили и небольшие сценарии конкретных страниц часто находятся прямо в HTML.

## Файлы верхнего уровня

| Файл | Назначение |
| --- | --- |
| [`Dockerfile`](Dockerfile) | Собирает образ на базе `nginx:1.27-alpine` и устанавливает конфигурацию из `nginx.conf`. Файлы `public/` копируются в образ внешней конфигурацией сборки проекта. |
| [`nginx.conf`](nginx.conf) | Настраивает раздачу статики из `/usr/share/nginx/html`, главную страницу, HTTPS и перенаправление с HTTP. Проксирует разрешённые запросы к API приложений `task-app` и `olymp-app`; неизвестные `/api/` возвращают 404. Маршрут `/tasks/<id>` отдаёт страницу поиска задач, которая сама загружает задачу по API. |

| [`olympiad-onboarding.html`](public/olympiad-onboarding.html) | Интерфейс пошагового подбора олимпиад: выбор вуза, направления и просмотр рекомендаций. Динамику обеспечивает `onboarding.js`. |

| [`olympiad-task-search.html`](public/olympiad-task-search.html) | Поиск и просмотр задач. Содержит экран результатов, фильтры и экран отдельной задачи; подключает `task-search.js` и `math-render.js`. Nginx также использует эту страницу для адресов `/tasks/<id>`. |

| [`olympiad-statistics.html`](public/olympiad-statistics.html) | Страница статистики с переключением периода, графиком, разрезами и архивом решённых задач. Ряды и большинство показателей заданы демонстрационными данными в HTML/встроенном сценарии; список дополнительно читает `maxolimp-solved` из `localStorage`. |
| [`olympiad-community.html`](public/olympiad-community.html) | Страница сообществ с карточками/ссылками на сообщества. Разметка и содержимое находятся в HTML; отдельная логика данных не подключена. |

## Скрипты `public/`

| Файл | Назначение |
| --- | --- |
| [`olympiad-shell.js`](public/olympiad-shell.js) | Регистрирует веб-компоненты `<olympiad-header>` и `<olympiad-nav>`. Компоненты отображают общий заголовок и нижнюю навигацию с активным разделом. |
| [`max-init.js`](public/max-init.js) | Читает `initData` MAX WebApp, отправляет его на `/api/max/validate` и сохраняет успешный результат в `sessionStorage`. Создаёт `window.maxUserReady` — Promise результата проверки. |
| [`onboarding.js`](public/onboarding.js) | Управляет шагами подбора: загружает вузы, программы и рекомендации через `/api/olympiads`, обрабатывает поиск, фильтр по льготам, избранное и этапы олимпиад. Сохраняет критерии и избранное в `localStorage`. |
| [`task-search.js`](public/task-search.js) | Загружает и отображает задачи через `/api/tasks`; управляет поиском, сортировкой, предметом, фильтрами, пагинацией и переходами браузера. Открывает условие, ответ и доступное решение выбранной задачи. |
| [`math-render.js`](public/math-render.js) | Преобразует поддерживаемую текстовую математическую нотацию и часть LaTeX-подобных команд в MathML. Если формулу разобрать не удаётся, оставляет исходный текст. |

## Стили `public/`

| Файл | Назначение |
| --- | --- |
| [`olympiad-layout.css`](public/olympiad-layout.css) | Общая структура основных страниц: flex-контейнер приложения, область содержимого, место для нижней навигации и высота шапки на узких экранах. |

## Связи страниц и компонентов

- Основные страницы подключают `olympiad-shell.js` для общей шапки и навигации.
- Подбор олимпиад использует `onboarding.js` и API `/api/olympiads/`.
- Поиск задач использует `task-search.js`, `math-render.js` и API `/api/tasks/`.
- `max-init.js` подключён на страницах, которым нужна проверка контекста MAX WebApp.
- `olympiad-layout.css` задаёт оболочку обычных страниц, а `olympiad-flow.css` — оформление сценариев и тренажёра. Остальные стили находятся непосредственно в HTML соответствующих страниц.
