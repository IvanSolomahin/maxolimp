# Статический UI

Приложение состоит из самостоятельных страниц в `public/`. Nginx отдаёт их напрямую;

- `olympiad-*.html` — разметка страницы и порядок подключения ресурсов.
- Одноимённый `olympiad-*.css` — стили конкретной страницы.
- Одноимённый `olympiad-*.js` — логика конкретной страницы, если она нужна.
- `olympiad-layout.css` — раскладка основных разделов; `olympiad-flow.css` — раскладка экранов сценария. Они подключаются после стилей страницы.
- `olympiad-shell.js` — общие шапка и навигация; `max-init.js` — инициализация MAX.
- `onboarding.js`, `task-search.js` и `math-render.js` — отдельные сценарии и вспомогательная логика соответствующих страниц.

При добавлении страницы держите разметку в HTML, оформление в CSS, поведение в JS. Сохраняйте порядок подключения общих CSS и JS: от него зависит поведение страниц без сборщика.
