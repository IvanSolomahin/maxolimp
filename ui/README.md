# Статический интерфейс

Приложение состоит из самостоятельных страниц в `public/`, без сборщика JavaScript. Образ из `Dockerfile` содержит только Nginx и `nginx.conf`. При запуске через корневой `docker-compose.yml` каталог `public/` монтируется в контейнер только для чтения, поэтому изменения HTML, CSS и JS становятся видны без пересборки образа.

## Где что находится

- `olympiad-*.html` — разметка страницы и порядок подключения ресурсов.
- Одноимённый `olympiad-*.css` — стили конкретной страницы.
- Одноимённый `olympiad-*.js` — логика конкретной страницы, если она нужна.
- `olympiad-layout.css` — раскладка основных разделов; `olympiad-flow.css` — раскладка экранов сценария. Они подключаются после стилей страницы.
- `olympiad-shell.js` — общие шапка и навигация; `max-init.js` — инициализация MAX.
- `onboarding.js`, `task-search.js` и `math-render.js` — отдельные сценарии и вспомогательная логика соответствующих страниц.

Главная страница — `olympiad-home.html`. Экран поиска задач — `olympiad-task-search.html`, решения — `olympiad-task-solve.html`, статистики — `olympiad-statistics.html`, каталога и онбординга — страницы `olympiad-onboarding.html` и `olympiad-after-onboarding.html`, сообществ — `olympiad-community.html`.

При добавлении страницы держите разметку в HTML, оформление в CSS, поведение в JS. Сохраняйте порядок подключения общих CSS и JS: от него зависит поведение страниц без сборщика.

## Маршрутизация и запуск

`nginx.conf` отдаёт `/` как главную страницу и отображает `/tasks/{id}` на страницу поиска. Запросы к `/api/tasks/` и `/api/progress/` уходят в `task-app`, к `/api/olympiads/` — в `olymp-app`; `/api/max/` и `/api/auth/` обслуживает `task-app`. Swagger UI обоих сервисов также проходит через Nginx. Остальные `/api/` возвращают 404. При изменении внешних URL сверяйте правила `rewrite` и `proxy_pass` в `nginx.conf` с путями FastAPI.

Интерфейс доступен по HTTPS на порту 443. В текущей конфигурации Nginx использует домен `gazprompt.duckdns.org` и сертификаты из `/etc/nginx/ssl/`. Для запуска на другом домене требуется обновить `nginx.conf` и монтирование сертификатов в корневом Compose-файле. Пошаговый запуск всей системы описан в [корневом README](../README.md).
